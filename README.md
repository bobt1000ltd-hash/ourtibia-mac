# OurTibia - macOS client build

Private. GitHub Actions builds `OurTibia.app` on macOS (Apple Silicon and Intel)
from `source/` (OTClient), with the newest modules from `client/` and the game
graphics downloaded from ourtibia.com. Result: workflow artifact
`OurTibia-macOS-<arch>` (zip, logs, screenshot).

Local build on a Mac: `./BUILD_MAC.command`.
